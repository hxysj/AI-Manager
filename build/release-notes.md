#- 新增私有远程更新检查能力。
  客户端可以直接检测私有更新源中的新版本，不需要额外部署服务端。这样可以继续保持仓库和安装包分发范围私有，同时让安装后的软件具备自动发现新版本的能力。

- 新增设置页手动检查更新入口。
  设置面板顶部的保存按钮旁增加了“检查更新”按钮，用户不需要退出软件或打开外部页面，就可以主动触发版本检查。开发模式、缺少更新配置、正在检查、正在下载、已是最新版本等状态会给出明确提示，减少点击后没有反馈的困惑。

- 新增托盘菜单检查更新入口。
  托盘右键菜单中也可以触发更新检查，应用最小化到托盘后仍然可以快速确认是否有新版本，适合长期后台运行时使用。

- 修复托盘 logo 消失问题。
  托盘图标改回固定使用应用图标，不再使用运行时动态生成的状态图。这样可以避免 Windows 托盘对动态图片渲染不稳定导致图标空白的问题，托盘入口更容易识别。
