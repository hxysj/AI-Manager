## 变更说明

- Codex 本地代理接管。
  新增 Codex 本地代理服务和接管开关，开启后会备份并改写 Codex Live 配置，让 Codex CLI 请求进入本地代理，再由接管池中的目标完成真实上游转发；关闭接管时会恢复原有 Codex 配置和之前的启用状态。

- 接管池管理和故障转移。
  新增独立接管池管理面板，支持把普通 Codex Provider 和官方账号加入接管池，手动切换当前激活目标，并在真实请求失败时自动切换到下一个可用目标，列表状态会跟随后端真实调用目标同步变化。

- Codex 代理请求日志。
  接管页面新增代理请求日志列表，显示全部保留的代理日志，并重新设计日志 UI；点击日志可打开右侧详情抽屉查看 Provider、Endpoint、上游地址、状态码、耗时、错误信息和上游响应内容。

- 官方账号代理转发修复。
  Codex 官方账号接管时复用已有的代理请求能力，避免官方账号上游被直连；修正官方 Codex 上游地址拼接，避免生成错误的 `/backend-api/codex/v1/responses` 路径，并修复 OAuth 刷新失败时 `[object Object]` 的错误提示。

- Provider 图标和接管交互优化。
  Provider 支持自定义上传图标，并优化 Codex Provider 页面代理开关、接管池入口、接管状态和 Provider 列表切换布局；接管池管理弹框只展示管理内容，避免混入完整代理面板。

- 用量统计归属优化。
  Codex 代理接管期间同步会话日志时，会将用量归属到当前真实接管目标，官方账号显示账号邮箱，普通 Provider 显示真实 Provider 名称，避免统计列表统一回退成 Codex。
