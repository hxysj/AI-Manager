## 变更说明

- 用量趋势统计增强。
  Skill 用量统计和全局用量统计新增趋势与占比图表，趋势图支持按住 Ctrl 后用鼠标滚轮细化 X 轴时间粒度，模型 Token 趋势也可以切换到 Provider 视角，便于按不同维度追踪消耗变化。
- Session 展示和详情修复。
  Session 列表标题优先使用用户发送的第一条消息，详情页补充展示系统工具调用类消息，减少标题误判和系统消息缺失的问题。
- 备份恢复批量选择优化。
  恢复预览中的冲突文件支持在分组或目录层级批量选择保留当前版本或使用备份版本，同时保留每个文件项的独立选择能力，降低多文件恢复时的重复操作。
- Skill 详情文件浏览增强。
  Skill 详情的 Files 页签新增目录树和内容预览，通过按需读取 Skill 目录查看 `SKILL.md` 之外的脚本、文档和配置内容，适配包含多目录资源的 Skill。
