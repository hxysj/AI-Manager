## 2.0.18 变更说明

### 新增 Claude Desktop 管理

- 新增独立的 Claude Desktop 管理入口，支持供应商查看、编辑、启用、禁用及多 API Key 配置。
- 支持由本项目本地网关接管桌面端请求，兼容 OpenAI 协议转换和实际模型映射。
- 桌面端会话和用量接入现有会话管理、用量统计界面，供应商详情支持查看用量。
- 调整桌面端 Skills 安装方式，使用个人 Skills 目录和清单注册，改善安装后无法识别的问题。

### 完善 API Key 管理与统计

- 新增逐 Key 请求次数、成功数、失败数、失败率、连续失败、进行中请求及最近请求与失败时间统计，支持自动和手动刷新。
- 统计按请求实际使用的密钥归属；改名或切换生效 Key 不串数据，替换密钥后独立统计。
- 重构管理弹框为 Key 列表与“配置 / 用量统计”分区，保留新增、删除、编辑和切换操作，明确区分当前生效与待应用状态。
- 优化窄窗口、短窗口及暗色主题显示，固定底部保存操作。统计仅覆盖经本项目发送的请求，直连与官方账号不计入。

### 优化云备份与恢复

- 云备份范围收敛为 Skills、Provider、Codex 官方账号、Rules、模型费用表及 Codex 宠物，不上传会话、用量、请求日志和云服务连接设置。
- 排除 Skills 依赖、缓存、Git 元数据及已知运行产物；宠物仅上传运行所需文件，保留 Skills 静态资源与规则。
- 云备份改为压缩后加密，恢复兼容旧版未压缩备份；优化大文件下载与恢复预览，改善响应体解码失败问题。
- 手动导出和本地自动备份保留原有范围，并补齐模型费用表；云端过滤不会删除本机文件。

### 改善工具与界面体验

- Skills 同名冲突列表区分新增导入项与现有项，并展示来源、描述和路径，便于选择保留内容。
- 增强 JSON 解析树与历史记录展示，字符串差异对比新增详情抽屉和高亮导航。
- 完善主题切换、状态标签和界面颜色，统一相关界面的视觉表现。

> 更新后需重新上传云备份，已有云端文件不会自动压缩或缩小。
