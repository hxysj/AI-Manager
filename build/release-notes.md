## 变更说明

- 禁用 Provider 和账号恢复。
  Provider 与 Codex 官方账号禁用后支持在列表和接管池中恢复，恢复只解除禁用状态，不会自动启用账号或切换当前运行目标，避免误改当前使用配置。

- Codex 代理日志筛选分页。
  Codex 代理请求日志新增成功、错误和全部筛选，并支持分页查看，减少日志较多时的列表压力，让排查当前接管请求更清晰。

- 禁用目标状态保护。
  禁用 Provider 后会阻止继续编辑和删除，接管池会识别禁用目标并禁止激活；恢复 Provider 只放行 `enabled: true` 的保存路径，避免绕过禁用状态修改配置。

- Proxy 状态展示。
  悬浮快速切换窗和托盘菜单在 Codex Proxy 开启时会显示 `Proxy 接管中` 和当前激活目标，列表中当前接管目标会标记为 active，托盘也提供关闭 Proxy 接管入口。

- 托盘图标保留。
  托盘状态展示改回使用原应用图标，避免动态状态图标导致 logo 消失，同时通过 tooltip 和菜单继续展示 Proxy 当前状态。
