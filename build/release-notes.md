## 变更说明

- 优化用量统计加载与刷新性能。
  初始状态改为轻量加载近期日志并按完整缓存汇总总量，刷新时复用未变化会话的缓存日志，减少启动和刷新时的重复扫描、重复计价与多余状态刷新。
- 支持 Claude 官方账号启动实例。
  Provider 模块新增 Claude 官方账号实例启动能力，并补齐运行时 Provider 调用参数和前端入口，方便直接管理 Claude 官方账号运行实例。
- 支持 Codex 官方账号启动实例。
  Provider 模块新增 Codex 官方账号实例启动能力，并优化相关运行时 Provider 逻辑，保持官方账号实例与现有 Provider 管理流程一致。
- 修复 CLI 检测和用量扫描范围。
  调整存储状态中的 CLI 检测逻辑和用量会话扫描范围，避免遗漏有效 CLI 数据或扫描到不应进入统计的数据。
- 修复 Git Tool 路径与应用日志异常。
  修正 Git Tool 路径处理和应用日志接口中的异常场景，提升 Git 工具数据读取与日志查看的稳定性。
- 优化发布工作流与协作规则。
  精简 release workflow 缓存配置并更新项目协作说明，减少发布构建重复工作，同时让协作约束更清晰。
