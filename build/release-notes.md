## 2.1.2 变更说明

### 日历与请假

- 日历移至主导航，启动时默认打开。可按天查看便签、提醒和模型用量，从日历打开对应日期的便签。
- 展示农历、节气、黄历宜忌、法定节假日和调休补班。自定义节假日和调休优先于公共安排，公共安排优先于大小周和双休。
- 右键日期可登记请假，支持单天、多天、全天或指定时段。AI 可根据文字或排班图片识别规则并记录请假，识别模型可单独切换。
- 月、周等视图切换时可复用已加载的数据，减少重复查询，缩短等待读取便签和用量的时间。

### 应用助手

- 扩展应用助手可直接调用的模块工具，覆盖日历、便签、Git、技能、规则等场景。助手会根据输入选择对应工具，在后台查询或执行。
- 操作、目标或关键参数有歧义时，助手先给出可点击的候选项，选定后再执行。

### Git 管理

- 分支提交记录支持按姓名或邮箱搜索并多选提交人，筛选覆盖当前分支的完整历史。
- 鼠标悬停在提交日期上时，以中文显示本地日期和时间。

### 工作留痕与其他工具

- 优化速记便签的工作留痕与工作小结流程，支持单独记录进度，保留原始记录，并完善分组、筛选和批量生成小结。
- 局域网共享新增设备 IP 变更通知，优化消息展示。

### 服务商与备份

- 同一服务商可管理多个 API Key，并查看密钥启用状态。模型目录按服务商保存。
- 新增 Antigravity 客户端集成，支持 Windows 安装检测和账号切换，优化多账号配额刷新。
- 备份可加密保存服务商 API Key 和官方账号登录凭据，方便在其他设备恢复。优化 WebDAV 临时故障重试。
