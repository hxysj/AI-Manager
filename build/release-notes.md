## 2.0.16 变更说明

### 新增 Provider 多 API Key 管理

- 同一个 Provider 现在可以配置多个 API Key，并为每个 Key 添加名称和备注信息。
- Provider 列表新增 Key 管理入口，可在弹框中添加、删除或切换当前生效的 API Key。
- 启用状态下切换 API Key 时会同步更新对应 CLI 配置；Proxy 接管期间会继续动态读取当前 Key，不会覆盖代理地址和托管认证配置。
- Codex 官方账号保持原有认证方式，不显示或写入 API Key 配置。

### 完善数据兼容与交互可靠性

- 多 API Key 数据支持加密备份和恢复，并兼容旧版本的单 Key Provider 数据。
- 修复新增或编辑 Provider 时添加 Key 失败的问题。
- 保存或同步失败时保留 Key 管理弹框及草稿，避免前后端状态不一致后丢失输入。
- 优化 Key 管理弹框的响应式尺寸和滚动区域，避免窗口较小或 Key 较多时内容被裁切。
