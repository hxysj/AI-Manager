## 变更说明

- 重构设备快传完整使用流程。
  新增局域网访问、二维码入口、设备识别、会话记录、消息通信、共享文件、文件预览和下载能力，让电脑端与移动端可以围绕同一设备会话完成文本和文件互传。
- 增强设备快传批量管理能力。
  支持批量选择消息和文件进行删除，补充全选、取消全选、清空会话、删除历史、刷新文件和导出压缩包等操作，降低大量消息或共享文件的整理成本。
- 优化设备快传访问与滚动体验。
  调整访问弹窗的信息层级、二维码展示、访问地址复制和关闭服务按钮样式；修复移动端页面设备名称区域被拉伸、消息列表内容超出后无法滚动的问题，使移动端页面高度分配更稳定。
- 完善 Skill 批量管理和分组筛选。
  支持批量选择 Skill 进行启用、禁用或删除操作，新增分组筛选和分类定位能力，提升大量 Skill 的查找、整理和统一维护效率。
- 同步应用版本和发布配置。
  更新前端、Tauri、Cargo 锁文件与发布说明中的版本相关配置，确保桌面端构建、安装包元信息和发布文档保持一致。
