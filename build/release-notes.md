## 2.0.27 变更说明

### 截图与文字识别

- 截图贴图从工具中心移至设置的功能扩展，支持独立启动、关闭并自动保存状态；关闭时释放快捷键与截图窗口，保留历史记录和配置。
- 新增本地 OCR 文字识别，模型随安装包提供；识别过程中显示加载提示。
- 智能选区支持识别 Windows 窗口与显示器，滚轮可切换嵌套选区，完善高亮、选框与窗口显示，减少闪烁。
- 长截图新增悬浮实时拼接预览，支持手动与自动滚动切换、Esc 快捷完成，并修复滚动时光标漂移问题。

### 设备快传

- 原生客户端支持加入群聊、同步群聊信息与收发消息和附件，并识别旧版客户端的群聊兼容性。
- 新消息支持系统通知、会话未读计数与悬浮窗徽标，修复消息到达后页面未刷新及多窗口未读状态不同步的问题；点击聊天区域也可清除当前会话未读状态。
- 同一设备切换 IP 后继续展示原有聊天记录，并在消息时间线居中标明 IP 变化；定期检测已连接设备，进入设备列表及向离线设备发送消息时主动确认在线状态与新 IP。
- 修复通过悬浮窗打开设备快传后，文件拖入输入区未显示上传入口、无法发送的问题。
- 完善图片、视频、音频、PDF 与文本文件预览，优化在线、隐身、离线状态显示和未选择会话时的界面。
- 删除设备后同步连接撤销状态，限制继续发送；删除单个设备时默认清理关联会话和历史记录，并支持一键清空全部连接设备、聊天记录与传输缓存。

### 划词与剪贴板翻译

- 支持自定义划词翻译、剪贴板翻译快捷键，修改后即时生效，并检查快捷键冲突。
- 配置与使用记录拆为独立弹框，入口放在启动按钮左侧。
- 优化翻译浮窗透明背景、结果展示与复制交互。

### 设置与桌宠

- 设置项修改后按字段自动保存，各模块仅保存自己的改动，移除手动保存按钮；连续操作按顺序保存，失败时恢复已保存状态。
- 系统设置拆为独立组件，统一为与功能扩展、桌面管理类似的卡片样式。
- 桌宠列表移入功能详情，支持切换桌宠与预览动作；启动时沿用上次激活的桌宠，首次使用默认启动第一只。
- 调整桌宠详情弹框宽度、标题字号与右侧操作布局，宠物和动作卡片随可用宽度自动换行。
- 修正猴子桌宠动作素材命名与对应关系。

### Git 管理工具

- 文件历史支持独立选择合入对比分支，切换后自动刷新，并避免旧查询覆盖当前分支结果。
