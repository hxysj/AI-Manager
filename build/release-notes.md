## 变更说明

- 新增实用工具大全面板。
  增加独立的 Toolbox 面板、前后端工具入口和工具注册机制，内置图片链接提取与字符串差异对比工具，让常用文本、链接处理能力可以直接在桌面端打开使用。
- 完善设备快传群聊与更新安装流程。
  扩展局域网快传的后端会话、消息和共享文件能力，前端补充群聊式工作区、会话操作和文件交互；同时完善应用更新检测、下载与安装流程，提升设备间传输和版本升级的连贯性。
- 修复 Skill 批量操作按钮状态。
  调整 Skill 页面批量启用、禁用、安装和卸载按钮的状态判断，避免无可操作项时仍显示可点击状态，降低批量维护 Skill 时的误操作概率。
- 实现模型用量报告长图导出。
  用量统计页补齐导出 PNG 长图能力，先选择保存路径，再将筛选条件、核心指标、趋势图、占比图、Provider 与模型统计绘制成图片，并由后端校验 PNG 数据后写入目标文件。
- 同步应用版本和发布配置。
  将前端包版本、Tauri 配置、Cargo 包信息、锁文件和发布说明统一更新到 2.0.7，确保桌面端构建产物、安装包元信息和发布文档保持一致。
