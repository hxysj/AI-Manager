## 变更说明

- 自定义应用更新提示面板。
  新增桌面端更新提示界面，集中展示版本信息、更新状态和用户操作入口，让自动更新流程更清晰可控。

- 模型费用配置增强。
  完善模型费用的导入导出能力，支持批量维护计费配置，并调整费用类型配置逻辑，减少重复编辑成本。

- 用量统计 Provider 绑定修复。
  新增请求记录持久化，避免同步时按当前 Provider 覆盖历史请求来源；会话日志变化时同步刷新用量，确保新日志及时绑定当时启用的 Provider。

- 用量筛选来源纠偏。
  刷新用量时按现有 Provider 信息修正历史请求记录中的 Provider 名称和类型，避免官方账号和普通 Provider 因同名显示在筛选项中重复出现。

- 云端恢复主要内容对比。
  恢复配置预览时仅对配置主体内容做冲突检查，忽略创建时间、更新时间、同步时间等元数据，减少无实际差异时的恢复确认干扰。

- 恢复差异检查弹框。
  恢复配置遇到冲突时，点击对比会打开独立差异弹框查看当前内容和备份内容，不再挤在恢复确认列表中，便于逐项检查后再决定保留或覆盖。

- 本地备份列表滚动。
  设置页本地备份列表增加高度限制，备份数量较多时在列表内部滚动，避免撑开设置页面布局。
