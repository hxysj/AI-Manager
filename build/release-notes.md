## 变更说明

- 用量统计时间筛选增强。
  将时间范围选择从固定的"今天/最近7天/最近30天/全部"改为日期时间范围选择器，支持自定义起止时间段查询和导出，让用量分析更灵活精准。

- 应用更新和启动优化。
  固定 Windows 安装包产物文件名为 Monkey-Thief-windows-setup.exe，避免更新器匹配 GitHub Release 资产失败；增加 Electron 单实例锁，重复启动时直接拉起已运行主面板，避免多开；限制检查更新弹框高度，内容过长时支持内部滚动。

- 构建产物体积优化。
  页面级组件改为异步加载，降低首屏主包体积；ECharts 和 Element Plus 改为按需引入，减少统计页和全局依赖体积；Monaco 改用 ESM 编辑器入口，并调整构建体积警告阈值以匹配桌面端实际依赖。
