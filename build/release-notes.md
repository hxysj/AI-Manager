## 2.0.22 变更说明

### 图像工作台与提示词库

- 重构图像工作台界面，增强轮次操作能力，完善生成结果复用、重新生成和删除等操作。
- 重构图像设置弹框，新增模型选择器和参数详情展示。
- 重构提示词库，增强模型支持，并补充提示词库测试脚本。

### Google 账号与供应商管理

- 新增 Google 账号登录、本地网关和会话管理能力。
- 增加账号相关数据存储、运行时代理和前端账号管理界面。
- 为供应商列表增加自动刷新和静默刷新机制。

### 局域网共享

- 增加消息重试能力。
- 增加自动发现开关。
- 新增全局配对弹窗，完善访问控制、会话工作区和消息面板交互。

### Git 管理器与工具中心

- 重构 Git 管理器和工具中心界面，完善本地分支、提交记录、提交详情、分支归档和 Stash 管理。
- 修复首次进入 Git 管理器时未自动检查提交是否已合入目标分支的问题。
- 重构 Codex Pet 管理器、提示词库和图像工作台在工具中心中的交互。

### 图片链接提取器与端口监控

- 重构图片链接提取器界面，增加代码编辑器和行号展示。
- 为端口监控工具增加自动刷新开关并优化操作界面。
