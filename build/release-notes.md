## 变更说明

- 新增 Codex 宠物管理。
  工具模块会在检测到本机安装 Codex 后显示宠物入口，直接扫描 Codex `pets` 目录，支持动画预览、修改名称、删除、禁用和重新启用。
- 宠物内容纳入备份与恢复。
  启用宠物会备份到独立的 Codex 宠物段并恢复到当前机器的 Codex 目录；已禁用宠物随应用数据目录一起备份和恢复。
- 修复 Usage 手动同步。
  手动同步日志后会刷新最新用量数据，避免继续显示过期的统计缓存。
- 完善 Windows 更新安装。
  下载完成后仅打开安装包；进程结束、旧版本卸载与用户数据清理选择均在安装程序中执行，避免重复确认和安装时序问题。
