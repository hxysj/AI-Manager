## 2.0.29 变更说明

### Provider 与账户管理

- 修复 Claude Desktop 密钥归属判断与保存逻辑，避免密钥保存到错误的账户。
- 优化 Provider 删除流程，直接在数据库中删除对应记录。

### 网络与代理

- 网络质量页面新增出口 IP 汇总展示。
- 支持 SOCKS 代理，并补充 Windows 系统代理检测。

### 截图与文字识别

- 引入 UI 元素检测模型，增强智能选区与区域候选识别。
- 使用边缘几何算法替换 ONNX 元素检测模型，减少模型依赖并优化检测流程。
- 重构 OCR 结果窗口，支持识别内容翻译。
- 修复截图贴图透明度样式应用位置，改善贴图显示稳定性。

### 设备快传

- 支持附件断点续传与双向传输进度展示。
