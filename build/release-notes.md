## 变更说明

- Provider 用量详情。
  Provider 和 Codex 官方账号详情新增用量页签，可查看请求次数、Token 总量、费用估算、Token 明细和按模型拆分的费用统计，账号用量同时兼容官方账号和代理接管池两种来源标识。
- 用量详情布局优化。
  详情抽屉的用量页面调整为主汇总块、Token 数据网格和模型费用列表，信息层级更清晰，适合在桌面端抽屉宽度内快速查看消耗情况。
- 备份恢复和更新安装流程完善。
  备份恢复预览、恢复执行、更新下载和安装流程继续补齐状态处理，让桌面端维护数据和升级应用时反馈更明确。
- 恢复配置关系修复。
  修复恢复配置时误取消启用关系的问题，避免恢复操作影响当前已启用的运行目标和配置状态。
