## 2.0.17 变更说明

### 扩展内嵌工具中心

- 新增 JSON 智能解析工具，支持自动格式化内容，并通过 Codex Agent 按指令修复异常 JSON。
- 新增字符串与 JSON 差异对比工具，可定位路径、行和字符级差异。
- 新增图片链接提取工具，可从文本、Markdown、HTML 或 JSON 中提取、选择和预览图片。

### 完善图片处理与导出

- 支持将选中的远程图片批量导出为 PDF 或 ZIP 文件。
- 图片列表改为按原始宽高比自适应展示，避免预览区域被固定高度压缩。
- 工具中心直接集成到主界面，统一工具切换、返回和侧栏交互。

### 修复公开版本更新

- 更新检查改为匿名读取公开 GitHub Release，避免内置 Token 失效导致 `401 Unauthorized`。
