## 2.0.19 变更说明

### 重构设备快传体验

- 支持客户端直连，保留扫码和网页接入方式；以聊天区为核心，将辅助管理操作整合到抽屉和弹框。
- 支持粘贴文件和图片、一次发送多个附件，多附件合并为一条消息；创建群聊至少需要邀请一台设备。
- 图片和文件支持直接点击预览，纯附件消息移除多余气泡，复制和删除操作与消息内容同排显示。
- 多图支持叠放展示、滚轮和方向键切换及切换动画；展开后逐张铺开，仅手动点击“收起”才折叠。
- 修复切图动画溢出导致的界面滚动，以及消息刷新时相册自动收起、当前图片重置的问题。
- 新增设备删除与二次确认，清理本机配对和单聊记录，保留群聊历史；已移除设备不再被自动发现立即加回。

### 完善供应商与 API Key 管理

- 改善 API Key 用量归属与统计展示，优化密钥输入框，支持查看未生效 Key 的内容。
- 删除供应商和官方账号前增加二次确认，统一确认弹框样式。
- Claude Desktop 导入增加预览与勾选弹框，由用户选择需要导入的配置。

### 改善数据恢复与界面显示

- 数据恢复合并本地与备份数据，仅针对冲突项选择保留版本，避免整体覆盖。
- 引入统一字号变量，调整工具详情和相关界面的字体显示，便于集中维护。
- 优化按钮宽度和文本显示，调整用量图表悬浮提示，仅展示有数值的项目。
