## 变更说明

- Provider 切换和运行时配置提示优化。
  Provider 列表补充备注展示，Runtime 配置不一致提示移动到切换操作旁边，差异对比忽略 `effortLevel` 和 `model` 字段，并在存在差异时使用独立边框状态提醒，避免和已有启用状态颜色混淆。

- 模型用量统计增强。
  进入用量统计页后每 60 秒自动同步会话日志，修正手动同步和自动同步的数据口径，Token 趋势图改为按模型维度展示，方便直接观察每个模型的 Token 使用变化。

- Codex 官方账号认证更新优化。
  刷新额度失败时提供更新认证信息入口，支持通过 OAuth 重新登录或重新导入 token 更新账号信息，并修复错误提示悬浮时超出容器看不见的问题。

- Codex 官方账号自动刷新优化。
  账号 token 检查改为按过期时间调度，30 分钟检查时会识别下一个检查周期前即将过期的账号，并在过期后 1 秒自动使用 refresh token 刷新，同时兼容 ISO 格式的过期时间。

- 应用更新下载错误提示优化。
  更新下载关闭差分下载以降低卡住概率，下载失败时会弹出消息提示，并同步输出到主进程和渲染进程 console，便于定位安装包更新问题。
