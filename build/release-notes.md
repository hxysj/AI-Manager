## 变更说明

- 快速浮窗交互优化。
  重构快速浮窗的默认用量摘要视图，打开后直接展示当前应用、Provider、请求数、Token 和费用，并可切换到 Provider 管理；同时优化最小化图标定位与动画，让收起和展开的位置更贴近浮窗中心，减少操作跳动感。

- 托盘 Provider 切换简化。
  调整托盘菜单布局，去掉重复的当前 Provider 信息区域，把启用入口直接放到 Provider 列表中，减少悬浮子菜单层级，让切换启用项更直接。

- 用量统计导出增强。
  模型用量页新增长图导出能力，导出文件名会包含当前筛选状态和时间；截图改为后台隐藏窗口生成，导出时不再闪动主窗口布局，并且隐藏请求日志、展开 Provider 统计和模型统计，保证导出图可完整阅读。

- 请求日志 CSV 导出。
  请求日志区域新增独立的 CSV 导出按钮，导出当前筛选条件下的全部请求日志，不受分页影响；导出内容包含时间、应用、Provider、来源、Session、模型、Token 和费用等字段，并在成功或无数据时给出消息提示。

- 开机自动启动设置。
  系统设置新增开机自动启动开关，用户可以自行开启或关闭；保存设置后会同步 Electron 登录项，避免需要手动配置系统启动项。

- 应用更新提示精简。
  修正应用更新弹框中“当前已是最新版本”等文案重复显示的问题，让标题和正文各自承担信息展示，减少弹框内容冗余。

- 备份和恢复体验优化。
  本地备份列表增加高度限制并支持内部滚动，避免备份较多时撑开设置页；恢复配置时仅比较主要内容，并使用独立差异弹框检查冲突内容，减少无关时间字段带来的恢复干扰。
