## 2.0.13 变更说明

### 新增本地端口监测与进程管理

- 工具模块新增 Windows 本地端口监测，可查看 TCP、UDP 监听端口及其所属程序、系统服务、PID、监听地址和可执行文件路径。
- 支持按端口、程序、服务或 PID 搜索，按协议筛选，并提供手动刷新与每 8 秒自动刷新能力。
- 支持确认后关闭端口对应进程；关闭前会重新校验 PID 和进程启动时间，避免 PID 被复用后误关其他进程，同时保护当前应用及系统关键进程。

### 优化 Provider 禁用项筛选

- Provider 列表默认隐藏当前 CLI 下已禁用的 Provider，以及 Codex 已禁用的官方账号，让常用启用项更易查看。
- 新增禁用项显示开关与数量提示，可按需查看全部禁用项，并完善无启用项时的空状态说明。

### 修复云端备份完整性校验

- WebDAV 云端备份上传完成后会再次读取远端文件大小，并与本地备份大小比对，及时发现上传截断或文件不完整问题。
- 读取被截断的加密备份时会明确提示备份文件不完整，便于重新生成或上传，不再只返回通用 JSON 解析错误。

### 修复 Codex 宠物备份过滤

- 宠物备份现在复用 Codex 宠物目录校验规则，只打包有效宠物目录，排除 `$out` 等构建产物和无效目录。
- 补充截断备份与无效宠物目录的回归测试，确保异常数据不会进入备份包。

### 修复用量统计时间范围选择

- 用量统计选择完整的开始和结束日期后会自动收起时间范围弹框，避免确认按钮隐藏后弹框持续停留。
- “全部时间”快捷选项应用筛选后也会自动关闭弹框，统一时间范围筛选的交互行为。
