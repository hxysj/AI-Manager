## 变更说明

- 模型用量统计面板。
  新增 Claude、Codex、Gemini 会话日志 Token 同步和统计展示，可查看真实消耗、缓存读取、费用估算、趋势图、请求日志、Provider 统计和模型统计。

- 模型费用配置。
  支持在用量页维护模型计费价格，按模型类别筛选和分页查看，编辑时再显示输入框，并支持美元、人民币和汇率换算显示。

- Provider 归类优化。
  会话日志同步时优先使用当前启用的 Runtime Provider 归类，无法确认时回退到 CLI 同名来源，请求日志中增加来源和 Session 信息，便于区分旧数据和当前会话。

- 诊断日志能力。
  增加后端调用日志记录、分类、成功失败状态和分页查看入口，方便排查云端恢复、同步和服务调用链路中的错误。

- 更新和会话体验优化。
  自动更新检查调整为主窗口加载完成后执行，设置页和托盘保留手动检查入口，Sessions 增加项目筛选并优化超长路径展示。

- 云端恢复与界面问题修复。
  修复从云端恢复数据时对象克隆错误的处理链路，并优化用量页滚动区域、固定头部、请求日志横向滚动和模型费用列表样式。
