## 2.0.20 变更说明

### 新增图片工作台

- 支持通过 Codex 官方登录账号生成和编辑图片，可选择或输入模型，设置提示词、尺寸、质量、数量和输出格式；图片编辑支持参考图与蒙版。
- 生成任务在后台执行，历史记录和图片保存在本地，支持状态筛选、自动刷新、查看参数、复用任务、批量删除和 ZIP 导出。
- 任务列表默认展示图片预览或生成中的加载状态，提示词与参数单独查看；支持查看原图、多图结果以及用生成结果继续编辑。

### 新增图片提示词库

- 内置提示词 JSON 数据，支持分类浏览、关键词搜索、分页加载、图片预览和导入词库。
- 支持中英文提示词切换、编辑并填入图片任务，入口位于创建任务头部。
- 词库底部注明 Toolcentral-ai / Image Prompt Gallery 来源并提供仓库链接。

### 升级划词翻译

- 支持使用大模型翻译软件内选中的文字，通过右键菜单发起翻译，覆盖普通文本、输入框与 Monaco 编辑器。
- 可在设置中选择 Codex 模式的 Provider 或官方账号、选择或输入模型并设置目标语言；官方账号翻译需要安装 Codex CLI。
- 翻译结果以可拖动浮窗展示，支持复制译文；本地保存翻译历史与请求消耗记录，可分页查看输入、输出、缓存命中和推理 token 用量。
- 修复 Windows 下 Node.js 启动时的扩展路径兼容问题，兼容普通盘符与 UNC 路径。

### 完善设备快传

- 附件列表、聊天消息和预览窗口支持通过系统保存对话框另存为，保存成功后可直接打开所在目录；已接收附件在快传服务关闭后仍可保存。
- 文件附件展示文件名，保存时阻止将副本写回源文件，避免损坏已接收的附件。
- 支持选择二维码与访问链接使用的局域网 IP，切换时无需重启服务，保留已连接设备的传输。
- 局域网 IP 列表去重，改进网卡读取失败提示，并限制仅在服务运行时切换访问 IP。
- 兼容新旧客户端设备 ID 格式，修复旧格式设备的发现与连接兼容问题。

### 修复工具显示问题

- 字符串差异对比支持长行自动换行，差异导航按换行后的实际位置定位，并改善高亮对齐与差异表格宽度。
- 修复图片链接提取工具中长图跨行重叠的问题。
