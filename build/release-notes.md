## 变更说明

- Skill 仓库功能新增。
  Skills 管理保留原本本地管理页，并新增 Skill 仓库入口，支持添加 GitHub 仓库、扫描仓库内以 `SKILL.md` 为入口的 Skill、查看详情，并在需要时安装指定 Skill 目录到本地。
- Skill 仓库扫描和安装优化。
  仓库扫描阶段只读取 GitHub 文件树和远程 `SKILL.md`，不再下载整个仓库；安装阶段才按选中的 Skill 目录下载文件，同时支持默认分支识别、重复 Skill 合并展示和多个仓库来源标识。
- Git 管理和备份逻辑优化。
  优化 Git 管理相关交互、归档恢复和本地缓存处理；云端备份不再包含 Git 管理缓存，本地备份仍可保留这些数据，减少云端备份体积和无关数据同步。
