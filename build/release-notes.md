## 2.0.30 变更说明

### 多协议模型网关

- 新增用量调度全景视图，集中展示请求量、成功率、Token 消耗、模型排行和费用概览。
- 新增输入 Token、输出 Token、缓存读取 Token、缓存输入 Token 统计。
- 新增缓存命中请求数、已测量请求数和缓存命中率展示，区分上游没有返回用量数据的请求。
- 适配 OpenAI Chat Completions、OpenAI Responses、Anthropic 和 Gemini 响应及流式事件中的缓存用量字段。
- 新增按客户端 IP 聚合访问次数、成功率、Token 和缓存指标，便于定位局域网客户端的调用情况。
- 新增按调用 Token、Provider、模型和 IP 查看用量聚合结果。
- 保留并恢复网关配置中的累计用量字段，避免配置规范化时丢失历史统计。
- 增加缓存 Token、客户端 IP 和用量聚合逻辑的测试覆盖。
