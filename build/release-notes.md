## 变更说明

- Git 管理分支和 Stash 归档能力增强。
  分支归档列表支持按分支类型分类、展开收起、按组恢复和全部恢复；Stash 支持多选后一键归档，并在归档、恢复、删除等确认操作后使用整页加载状态，减少操作期间的误触和状态不一致。
- Git 提交检查准确性优化。
  检查提交是否存在于指定分支时，先使用 commit hash 精确比对，hash 不一致时再使用提交消息和提交时间同时匹配，避免仅凭相同提交消息造成误判，并同步更新检查缓存键。
- Git 管理交互细节优化。
  分支列表新增右键复制分支名，归档列表超出时可滚动，归档详情保留返回列表入口，分支和归档分类均支持展开关闭，提升日常分支整理和排查效率。
- 添加项目流程性能优化。
  添加项目成功后只更新仓库列表状态，不再立即触发全量刷新、Skill 扫描和全仓库文件监听重启，避免大仓库添加时导致桌面端卡顿或退出。
- Skill 仓库样式修正。
  优化 Skill 仓库列表相关样式展示，使仓库来源、Skill 信息和操作区域在当前桌面端布局中更稳定清晰。
