## 2.0.21 变更说明

### 完善 Web 与 Codex 生图

- 新增 Web 生图模式并默认选中，使用所选账号的 ChatGPT 网页端额度；页面头部可切换 Web / Codex，任务记录保留实际调用模式。
- 模型目录动态获取，支持刷新和手动输入；Web 模式展示账号剩余生图次数、额度恢复时间及查询状态，任务结束后自动刷新额度。
- 支持自定义宽高、宽高比和尺寸预设，按模型提供质量选项；单次最多提交 100 张图片，每张建立独立任务并按轮次展示。
- 新增草图绘制和结果图蒙版标注，支持画笔、橡皮与笔刷大小调节；参考图支持上传、粘贴、拖拽和引用生成结果。

### 完善任务与会话管理

- 新增本地会话历史，支持新建、切换、重命名、删除和清空；顶部可直接重命名当前会话，手动设置的名称不再被生成提示词覆盖。
- 任务列表默认每页显示 50 条生成记录，可切换为 10、20、50 或 100 条并记住选择；切换条数时返回第一页，完善分页栏间距。
- 支持复用整轮配置、整轮或单张重新生成、删除生成结果；Web 任务中断后可继续等待原会话结果，并支持排队任务恢复。
- 生成图片详情改为左右布局：左侧 75% 展示图片，右侧 25% 显示尺寸、格式、调用模式和模型，并集中提供编辑、引用与下载操作。

### 修复 Web 图片下载

- 修复 Web 生成结果下载时缺少原账号认证导致的失败，完善图片资源未就绪、临时网络异常与过期下载地址的重试和错误提示。
- 暂时的轮询或部分图片下载失败时保留已获得的生成结果，支持继续获取剩余图片。

### 更新图标与开发体验

- 更换应用 Logo 与安装程序图标，更新侧栏和悬浮入口，保留透明背景并修正图标裁剪。
- 开发启动时自动选择可用端口，避免默认端口被占用导致启动失败。
