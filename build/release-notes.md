## 2.0.15 变更说明

### 新增 Codex 官方账号额度阶段统计

- Codex 官方账号登录或刷新额度后，按主要和次要额度窗口的重置时间记录当前阶段；重置时间变化时自动归档旧阶段。
- 账号详情的用量面板新增额度阶段卡片，展示已用和剩余百分比、Token、请求数、已计费金额与阶段时间，并保留最近的历史阶段。
- 每条用量日志首次计费时固化模型价格、汇率和费用快照；后续修改模型价格不会重算已产生费用，Session 重新解析时也会保留原计费快照。
- 额度阶段与用量计费属于本机运行数据，不参与跨设备备份恢复。

### 保留同步数据的本机启用状态

- Provider、Codex 官方账号和宠物同步时保留本机的启用或禁用状态，云端备份不再覆盖当前设备的运行选择。
- 备份中新增的 Provider、Codex 官方账号和 Skill 默认禁用，避免恢复后立即改变本机运行配置。
- 宠物同步只导入本机不存在的宠物 ID；无论本机宠物当前启用还是禁用，都不会被同步数据重复创建或改变状态。
- 备份差异比较会忽略这些本机状态字段，避免仅启用状态不同时产生无意义的冲突。

### 优化同步数据差异定位

- 恢复预览导航改为按实际同步数据的最外层路径聚合，直接显示主数据库、Provider、Codex 官方账号、Skill、Prompt 和宠物等数据来源。
- 每个导航项显示路径、新增数量和冲突数量，同步项较多时可以快速定位具体差异。
