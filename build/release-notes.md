## 变更说明

- 优化 Codex Runtime 配置写入。
  合并更新 `config.toml` 时保留用户已有配置，只写入当前 Provider 运行所需字段；同时完善模型思考强度选项和配置比较规则，避免非托管字段导致误判。
- 将核心业务数据统一迁移到 SQLite 主数据库。
  把 Usage、Skills、Prompt Rules、Provider 配置、模型信息和 Codex 官方账号统一存入 `ai-manager.db`，补充查询索引和事务迁移，减少大规模 JSON 读取带来的等待时间。
- 完善旧数据迁移与数据库备份恢复。
  应用启动后自动迁移旧 JSON 和独立 Usage 数据库，迁移成功才删除旧文件；备份使用 SQLite 在线快照，并排除用量同步记录、密钥和设备 Runtime 状态等不可跨设备恢复的数据。
- 修复 Windows 更新安装顺序。
  更新时先关闭当前程序并在原安装目录等待旧版本完全卸载，再打开新版本安装面板，避免卸载未结束就启动安装，同时保留用户在安装面板中选择是否删除数据的流程。
