## 2.0.12 变更说明

### 完善 Skill 分组与卸载流程

- 重构 Skill 分组管理界面，支持新建分组、行内重命名、删除确认和复制分组 ID，并改善列表、焦点与操作反馈。
- 完善批量移动到分组的交互，集中展示已选 Skill、目标分组、缺失项和本次新增数量，移动结果更清晰。
- 普通卸载会直接复用 Tauri 卸载页的用户数据清理勾选状态，不再重复询问；升级卸载仍沿用安装器中的清理选择。

### 修复 Provider 切换后的用量归属

- 切换 Provider、Runtime、代理或 Codex 账号前会先同步尚未入库的用量，避免切换前产生的请求被记到新 Provider。
- 设置界面与托盘菜单的切换路径统一执行用量同步，确保不同入口的统计行为一致。
- 增加跨 Provider 用量归属回归测试，验证切换前后的请求会分别归属实际使用的 Provider。

### 新增 Koofr 云同步

- 数据管理新增 Koofr WebDAV 同步，可独立配置 WebDAV 地址、备份文件名、账号和应用密码。
- 支持将加密配置备份推送到 Koofr、查看云端备份内容，以及从 Koofr 兼容恢复配置数据。
- 坚果云与 Koofr 使用两套独立配置和同步时间，切换同步目标时不会互相覆盖账号或备份地址。

### 完善云端备份兼容

- 加密备份现在同时保存坚果云与 Koofr 的同步配置，恢复时可分别选择对应配置。
- 继续兼容只包含坚果云配置的旧备份，恢复旧备份时会保留当前 Koofr 设置。
- 云端备份查看与恢复预览会统一隐藏两套 WebDAV 应用密码，避免敏感信息泄露。
- 推送、下载、目录创建和文件不存在等提示会显示实际云服务名称，便于定位配置问题。
