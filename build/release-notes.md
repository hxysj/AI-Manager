## 变更说明

- 回滚运行性能优化改动。
  回退此前引入的启动按需刷新、运行时追踪降载、划词翻译 Worker 等性能优化改动，恢复原有运行链路，避免这些优化影响现有功能稳定性。
- 优化 GitHub Skill 仓库添加流程。
  添加、刷新和删除 Skill 仓库后只更新仓库列表状态，不再立即触发全量刷新；同时调用日志只记录结果摘要，减少添加 GitHub 仓库时的主进程序列化压力和界面卡顿。
- 修复划词翻译弹框关闭逻辑。
  切换页面时自动关闭划词翻译弹框，并阻止已关闭弹框继续接收异步翻译结果，避免弹框残留在其他页面。
- 恢复无痕卸载入口。
  设置页重新提供无痕卸载按钮，触发后会清理本地用户数据并静默启动应用卸载程序。
