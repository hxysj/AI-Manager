## 2.0.23 变更说明

### 桌宠与悬浮工具

- 新增桌宠展示与选择，支持 16 种动作的精灵图逐帧播放和独立帧间隔配置。
- 修正动画裁切和贴边显示，偷看动作的墙壁保持固定；缩小桌宠尺寸，减少遮挡。
- 左右贴边播放偷看动作，上下贴边保持普通动作和原有纵向位置；悬浮时敬礼，拖动时行走。
- 提前加载并复用悬浮窗，预加载动作素材，减少主页面隐藏后的等待和中央图片短暂空白；隐藏时暂停动画。
- 修复拖动到边界后悬浮无法展开、窗口重载后交互状态不同步的问题。
- 工具节点根据屏幕边缘的可用空间自动调整布局，支持直接打开对应工具。

### 图像工作台与批量生成

- 新增批量图片生成，支持任务导入、并发设置、暂停与继续、失败重试和批量导出。
- Web 模式在同一会话中依次生成图片，持久保存会话，保留至手动删除；完善中断后的生成恢复。
- 根据实际生成的图片数量更新额度，改进任务队列、结果详情、分页和加载遮罩显示。

### Git 管理器

- 新增分支对比，支持相同分支对比，优化提交、文件差异和对比面板交互。
- 完善提交详情和操作确认，支持提交、拉取、推送、合并、挑选提交、撤销提交和重置等 Git 操作。

### 新增工具

- 新增网络质量监测，支持选择诊断地址族和检测项、查看诊断进度、取消诊断及导出 JSON 报告。
- 新增坐标框预览，支持解析题目 JSON，在题目图片上显示题框和作答框，并按题目控制显示范围。

### 代理、设备快传与应用更新

- 新增模型别名映射和 Codex 模型目录支持，完善代理实例管理与启动流程。
- 改进设备快传的设备发现协议。
- 支持 Windows 静默安装更新，安装完成后自动重启应用。
