## 2.1.0 变更说明

### 本地模型与翻译

- 新增 Qwen3.5-0.8B 本地模型，下载并校验完成后，可用于离线翻译和应用助手。
- 本地助手支持文本对话、工具调用和流式回复，同一轮工具续答复用模型，任务结束或取消后释放模型进程。
- 翻译、OCR 和助手按用途显示已安装模型，下载或删除后自动更新可选列表；修复本地助手已选中模型却无法发送消息或压缩上下文的问题。
- 内存预算改为运行参考，不再阻止模型下载；继续检查系统架构、磁盘空间和文件完整性，运行时按模型要求检查资源。

### 应用助手

- 新增应用助手，支持独立对话窗口、桌面悬浮输入、快捷键唤出和桌宠回复。
- 支持会话历史、自动与手动上下文压缩、跨会话公共记忆，以及助手独立的技能和工具管理。
- 配置查询、生图、Agent 来源切换等常用操作默认通过内部接口在后台完成，避免逐步点击和自动聚焦窗口；JSON 编辑器支持后台读写。
- 完善任务取消、历史恢复和错误提示，保留上游接口返回的具体错误信息。

### 服务商与账号管理

- 新增统一服务商配置中心，集中管理 API 服务商、GPT 官方账号和 Google 官方账号，支持旧配置迁移。
- Codex、Claude Code 和 Claude Desktop 可分别选择服务商、默认模型和独立参数，支持停止使用并恢复原有配置。
- 支持官方账号登录、导入和额度查询，优化账号概览、服务商详情、关联 Agent 与快捷切换面板。
- 支持 Codex 模型目录同步开关和 Claude Desktop 模型档位映射，并提供模型兼容性测试与网关管理。

### 配置恢复与协议兼容

- 修复修改单个 Agent 配置时，误将同一服务商下其他 Agent 标记为未同步、导致请求被拒绝的问题。
- 恢复配置时只撤回仍未被修改的接管字段，保留客户端后续添加或修改的项目、插件等设置，避免整文件校验导致无法停止使用。
- 所有配置文件先检查再恢复，恢复成功后才撤销访问令牌，避免恢复失败后客户端也无法继续使用。
- 修复 Claude 转 OpenAI Chat 和 Responses 时的消息角色处理，完善源码附件、图片、工具调用及工具结果转换，保留流式响应。

### 用量与界面优化

- 统一共享网关的请求、用量和技能调用统计，完善缓存 Token 记录、模型价格继承和历史费用补算。
- 官方账号身份、认证信息和额度作为本机数据保存，配置备份与恢复保留本机凭据。
- 调整功能扩展顺序，将“本地大模型”放在“应用助手”之前。

### 应用更新

- 统一应用版本、更新公告、安装包和自动更新元数据的版本来源，启动和构建时自动检查并同步版本信息。
