## 2.0.26 变更说明

### 应用更新

- 更新后首次打开主界面时居中展示本次更新公告，确认或关闭后同版本不再提示，下次升级后重新展示。
- 公告随安装包提供，支持离线查看、滚动阅读与深浅主题；工具窗口和悬浮窗不弹出公告。

### 截图区域识别

- 根据当前截图内容自动识别矩形区域，支持悬停高亮、点击选中与拖动自定义选区。
- 限制识别采样尺寸并过滤重叠候选，取消或重置截图时同步清理区域状态。

### 设备快传

- 连接弹框主动扫描局域网设备，经对方确认后建立连接，支持隐藏节点与连接状态同步。
- 已连接设备与群聊成员支持在线状态检测，完善群聊成员管理与退出处理。
- 删除设备时可选择同时彻底清理聊天记录和相关文件。
- 优化文件分块重试、传输进度和已送达状态，复用传输缓冲并限制连接并发，减少大文件传输消耗。
- 增加访问令牌定期轮换，完善二维码连接流程。

### Git 管理工具

- 支持工作树创建与切换，仓库操作使用当前选中的工作树并校验路径，隔离不同工作区的状态。
- 新增文件树与文件提交历史查询，支持快速定位文件并查看修改过该文件的提交。
- 合入检查增加提交标题、作者相似度与改动内容一致性判断，悬浮可查看判定原因。
- 完善提交切换、操作中文提示、命令悬浮说明与下拉菜单交互。

### 图片工作台与性能

- 图片文件移至目录存储，生成结果按会话归档，并迁移合并历史图片；任务记录保存图片标识与引用关系。
- 移除持久化缩略图，预览按需生成并分批加载，限制临时预览缓存，减少数据库与内存占用。
- 图片列表与预览查询移至后台线程，避免阻塞主界面；记录上游会话删除状态，防止重复恢复。
- 主面板打开后关闭独立工具窗口，减少隐藏窗口占用，保留截图与贴图的独立生命周期。

### 数据存储与备份

- 修复旧版数据升级后启动失败，兼容旧供应商与密钥关联、图片任务、提示词分类和早期用量数据；迁移中断后可继续补齐，成功后移除旧表。
- 重构技能、规则、用量、供应商与翻译数据的结构化存储，合并冗余表，迁移历史数据后移除旧表。
- 技能仅缓存描述，正文按需读取；简化分组、安装和回收站记录，将技能调用关联到会话用量。
- 统一供应商与账号配置，密钥独立管理；更换或删除密钥时保留历史用量归属，合并仓库缓存与统计记录。
- 备份按白名单导出业务配置，排除图片、本机运行状态及仓库缓存，清理残留快照并兼容旧版备份。
- 统一新记录的标识生成并保留历史关联，完善数据库迁移回滚、并发初始化与恢复处理。
