## 变更说明

- 优化应用启动性能。
  启动时优先读取本地缓存状态，不再立即执行全量 CLI 检测、Skill 扫描、Session 扫描和 Usage 重算；运行态、Prompt 漂移和账号刷新改为轻量后台处理，减少首次进入应用时的卡顿。
- 调整 Session 和 Usage 的刷新时机。
  Session 文件监听和 Usage 重新计算改为进入 Usage、Sessions 或 Skill Usage 页面后才启动，离开页面后自动停止；手动同步仍会扫描 Session 并重新计算用量，保证需要查看用量时数据可以刷新。
- 优化 Skill 仓库扫描体验。
  进入 Skill 仓库页面只读取本地缓存，只有点击刷新才重新扫描 GitHub；新增、刷新和删除仓库后只更新仓库状态，不再触发本地 Skill 全量刷新，并减少扫描结果缓存体积和网络并发，降低大仓库导致软件卡退的风险。
- 优化设置保存性能。
  保存坚果云、本地备份、关闭行为和自启动等普通设置时，不再重新检测 CLI 和全量刷新；只有数据目录或 CLI 配置目录变化时才重新检测运行路径，让设置保存更快完成。
- 减少运行期后台开销。
  Usage 日志初始化不再额外排队写入，Codex 账号过期检查延后启动，应用状态订阅顺序也做了调整，降低启动阶段 I/O 和状态推送压力。
